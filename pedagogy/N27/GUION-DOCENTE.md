# N27 · Guion visual y notas docentes

## Función del soporte visual

El soporte superpone cuatro contratos sobre la misma interacción y conserva sus pruebas.

| Pantalla | Qué se ve | Nota de orador | Señal para avanzar |
|---:|---|---|---|
| 1 | Pregunta profesional de N27 | Preguntar qué falta aunque el JSON valide. | Aparecen significado, tiempo y operación. |
| 2 | API como acuerdo parcial | Separar interfaz de promesa completa. | Se reconocen consumidores. |
| 3 | Prueba sintáctica negativa | Romper tipo o campo. | La incompatibilidad se detecta. |
| 4 | Dos significados de disponible | Pedir autoridad semántica. | Estado e invariante se acuerdan. |
| 5 | Línea temporal | Reordenar mensajes. | Se define vigencia y decisión. |
| 6 | Reintento duplicado | Perder una respuesta. | La operación es idempotente o limitada. |
| 7 | Contrato de error | Exigir acción posible. | El error orienta reparación. |
| 8 | Guardia HH-27 | Quitar al equipo de desarrollo. | Existe soporte y escalamiento. |
| 9 | Dos versiones vivas | Probar convivencia y retiro. | La migración es verificable. |
| 10 | Puente a N28 | Convertir confianza en reclamo de calidad. | Aparecen escenario, riesgo y evidencia. |

## Preguntas de sondeo

- ¿Qué garantiza realmente la API?
- ¿Quién define el significado?
- ¿Cuándo vence este dato?
- ¿Qué pasa si se repite el comando?
- ¿Cómo se repara este error?
- ¿Qué consumidor impide retirar la versión?

## Errores esperables

### OpenAPI como contrato total

Intervención: introducir significado, tiempo y guardia nocturna.

### Reintento automático

Intervención: mostrar un efecto no idempotente.

### Error genérico

Intervención: pedir correlación, estado y acción siguiente.

### Versión nueva como migración

Intervención: mantener un consumidor anterior en producción.

## Decisiones de facilitación

- Si el debate se vuelve tecnológico, volver a la promesa de servicio.
- Si el contrato parece completo, ejecutar demora y duplicación.
- Si se evita la transición, exigir fecha y evidencia de retiro.
- Si falta tiempo, reducir formatos, no semántica ni migración.
