## Preguntas de sondeo

- ¿Calidad para qué uso y población?
- ¿Qué daño se intenta evitar?
- ¿Qué prueba distingue las explicaciones?
- ¿Quién define el oráculo?
- ¿Qué esconde el promedio?
- ¿Qué concesión se acepta y revisa?

## Errores esperables

### Calidad como perfección

Intervención: introducir atributos incompatibles y capacidad finita.

### Cobertura como confianza

Intervención: mostrar una población ausente.

### Umbral retroactivo

Intervención: fechar el criterio antes del resultado.

### Evidencia sin decisión

Intervención: retirar toda prueba que no cambie una puerta.

## Decisiones de facilitación

- Si se acumulan métricas, volver al riesgo.
- Si el oráculo depende del autor, convocar a Operaciones o usuarios.
- Si accesibilidad queda como promedio, desagregar por episodio.
- Si falta tiempo, reducir reclamos, no población invisible ni tensión.
