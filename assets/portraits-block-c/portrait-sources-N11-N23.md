## Criterio de aceptación

Sólo se considera `approved_open_reuse` una fotografía decodificable que representa inequívocamente a la persona, tiene página fuente HTTPS, autor o crédito, y licencia abierta, dominio público o política institucional de reutilización comprobable. Un activo heredado con procedencia pero sin licencia explícita se conserva para trazabilidad, pero queda `not_release_approved`. No se usaron monogramas, logos, punteros LFS, retratos generados ni likeness inventados.
