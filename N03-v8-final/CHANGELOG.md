# Changelog, N03 v8 final

## 3 de septiembre de 2026

- Se reemplazó la fuente histórica v7 por el manuscrito canónico final de N03, sin modificar una palabra de ese contenido.
- Se recompaginó la lectura en 30 páginas A4 con 11 secciones numeradas y Referencias base como aparato SIN NUM.
- Se incorporaron los tres movimientos canónicos, la continuidad HH-03 y el puente explícito desde N02 hacia N04.
- Se fijaron dos pausas fotográficas internas a página completa, la primera inmediatamente después de la página 4.
- Se reconstruyó el eyebrow de tapa como dos cadenas completas y extraíbles.
- Se incorporaron cuatro retratos distintos y del mismo tamaño para las voces de Hotel Horizonte.
- Se aplicó el cierre estructurado de fósforos con folio, línea de pie, pie de imagen y texto alternativo, sin frase superpuesta.
- Se compactó Referencias base en dos columnas y se protegieron las siete URLs para que los saltos ocurran sólo entre segmentos, nunca dentro de un guion.
- Se añadió una validación determinista específica para N03 v8 y un handoff autosuficiente.
- Se reemplazó la tapa inicial por una fotografía cinematográfica de producción editorial, protagonizada por una trabajadora hotelera argentina y concebida para convivir con la composición aprobada sin moverla.
