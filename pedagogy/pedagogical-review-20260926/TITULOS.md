# Títulos de las 36 lecturas

Título breve para abrir la lectura; subtítulo para precisar su alcance académico. N00 sigue siendo la guía, no una lectura adicional.

| Lectura | Título | Subtítulo |
|---|---|---|
| N01 | Intervenir sin recetas | Metodología y juicio profesional cuando el problema todavía no está claro |
| N02 | Un sistema es mucho más que una aplicación | Personas, reglas, información y tecnología en un sistema de información |
| N03 | Resolver acá, complicar allá | Fronteras del sistema, retroalimentación y efectos no intencionales |
| N04 | Antes de decidir, ¿qué sabemos? | Cómo distinguir hechos, síntomas, relatos, hipótesis y decisiones |
| N05 | No todos ven el mismo problema | Actores, personas afectadas, poder y perspectivas |
| N06 | Investigar antes de apostar | Discovery: reducir incertidumbre para elegir el siguiente paso |
| N07 | Preguntar para entender | Entrevistas, evidencia y necesidades más allá del pedido de requisitos |
| N08 | El trabajo que no aparece en la pantalla | Observación de la actividad, excepciones y coordinación cotidiana |
| N09 | Diseñar para quienes lo van a usar | Experiencia, accesibilidad y adopción a lo largo del servicio |
| N10 | Del síntoma al problema | Construcción del problema y definición de resultados verificables |
| N11 | ¿Qué demuestra este dato? | Calidad de la evidencia, inferencias y límites de una afirmación |
| N12 | Pedir no es confirmar | Eventos, estados, comandos y autoridad para cambiar un sistema |
| N13 | ¿Qué pasa si el pedido llega dos veces? | Demoras, concurrencia, consistencia, idempotencia y reconciliación |
| N14 | De un área a otra: dónde se frena el trabajo | Procesos de principio a fin, traspasos, esperas y excepciones |
| N15 | Un modelo para cada pregunta | Selección de modelos según el propósito, las personas y el costo |
| N16 | Cuando los modelos no coinciden | Contradicciones, validación y mantenimiento de representaciones |
| N17 | No todos los cambios se hacen igual | Lógicas predictiva, iterativa, incremental, experimental y adaptativa |
| N18 | Cambiar sin romper lo que funciona | Legado, restricciones y capacidades que vale la pena conservar |
| N19 | ¿Comprar, construir o no automatizar? | Alternativas de realización, integración, costos y condiciones de salida |
| N20 | Del plan a las decisiones | Estrategia de intervención, hitos, autoridad y criterios de cierre |
| N21 | El proyecto termina. El servicio sigue. | Proyecto, producto, servicio y plataforma: responsabilidades que continúan |
| N22 | Probar antes de ir más lejos | Hipótesis de valor, evaluación y decisiones sobre una iniciativa |
| N23 | Una entrega pequeña que ya sirva | Cortes de punta a punta, MVP y aprendizaje con uso real |
| N24 | Si todo es urgente, ¿qué va primero? | Priorización, capacidad, dependencias y costo de demora |
| N25 | Empezar menos, terminar más | Flujo de trabajo, límites de WIP, colas, lotes y retroalimentación |
| N26 | Un servicio, muchas organizaciones | Arquitectura de servicios, plataformas y dependencias de terceros |
| N27 | Entender lo mismo antes de conectar | APIs y contratos de intercambio: significado, tiempo y operación |
| N28 | Funciona, pero ¿funciona bien? | Atributos de calidad y evidencia de un servicio adecuado al uso |
| N29 | Cambiar sin dejar de atender | Entrega continua, exposición, recuperación y control del cambio |
| N30 | Detectar, responder y aprender | Observabilidad, objetivos de servicio, incidentes y aprendizaje operativo |
| N31 | ¿Para qué usar IA y hasta dónde? | Selección de usos, capacidades y límites de autonomía |
| N32 | ¿Está lista esta IA para usarla? | Evaluación situada, cobertura, gravedad de errores y supervisión |
| N33 | La IA cambió. ¿Sigue siendo confiable? | Gobierno del uso, seguimiento de cambios, incidentes y retiro |
| N34 | Que las decisiones encajen | Trazabilidad del problema, la evidencia, las decisiones y los resultados |
| N35 | Explicar para que otros puedan actuar | Argumentación, comunicación y transferencia de decisiones |
| N36 | ¿Qué aprendimos de lo que hicimos? | Reflexión sobre la práctica, revisión y aprendizaje profesional |
