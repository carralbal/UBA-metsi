# N35 · Rúbrica y evidencias

## Escala

- `0`: presentación genérica;
- `1`: adaptación superficial o persuasiva;
- `2`: defensa útil con operación o transferencia incompleta;
- `3`: comunicación situada, íntegra, objetable y transferible.

## Rúbrica de defensa y transferencia

| Criterio | Pregunta de evaluación | Evidencia de nivel 3 |
|---|---|---|
| Audiencia | ¿La pieza responde a una decisión real? | Ajusta jerarquía, detalle y acción. |
| Tesis | ¿La afirmación es clara y discutible? | Conserva consecuencia, evidencia y límite. |
| Integridad | ¿El criterio permanece entre versiones? | No cambia garantía para persuadir. |
| Evidencia | ¿La procedencia puede examinarse? | Distingue dato, inferencia e incertidumbre. |
| Objeción | ¿La crítica modifica el razonamiento? | Se responde, registra o revisa con criterio. |
| Operación | ¿El material permite actuar? | Incluye señales, autoridad y excepciones. |
| Afectados | ¿La comunicación reconoce derechos? | Explica decisión, impugnación y reparación. |
| Transferencia | ¿El criterio funciona en otro caso? | Produce decisión situada sin copiar solución. |

## Evidencia de aprendizaje

La comunicación debe permitir que otra persona use el criterio en un dominio nuevo y explique qué no puede trasladarse.

## Conexión acumulativa

La sorpresa producida por las audiencias alimenta la revisión reflexiva y el sistema de aprendizaje profesional de N36.
