# N17 · fuente editorial post-Cecilia

`index-release.html` es la fuente editable de la revisión digital N17 de 45 páginas, `n17-prefact-post-cecilia-20261027`. El paquete contiene sólo los CSS y recursos referenciados por la fuente final. La cubierta aprobada se toma del PDF público anterior durante el ensamblado.

## Cambio curricular

El N17 anterior explicaba lógicas de intervención, pero no realizaba un estudio integrado de prefactibilidad. Se agregó una sección de **núcleo** tras el instrumento HH-17 y antes del caso hospitalario. Una señal no solicitada sobre constancias lleva a evaluar viabilidad técnica, operativa y económica, límite de 40 horas, decisión de piloto restringido y condiciones de freno. La pregunta de preparación permite rehacer la decisión con 30 horas y un aviso fallido. N19 retoma la misma constancia cuando se considera consultar proveedores.

La fusión es **aditiva**: los 316 bloques de contenido público anterior conservan exactamente su texto; el caso hospitalario sigue como extensión. Se suman ocho bloques de explicación/caso y uno de práctica. El índice y las referencias se sincronizaron con el nuevo folio 44.

No se incluyen los ensayos privados ni variantes sustitutorias. El producto es digital; siguen abiertas la validación académica, la carga real de lectura, la accesibilidad humana y la preparación de imprenta.
