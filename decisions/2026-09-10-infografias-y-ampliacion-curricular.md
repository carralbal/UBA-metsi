# Decisiones aprobadas para la siguiente evolución de METSI

Fecha de aprobación: 10 de septiembre de 2026.

Alcance: colección N00 a N36.

## Estado de las infografías

La serie presentada en `output/pdf/METSI-catalogo-infografias-N00-N36-revision-v3.pdf` queda aprobada de manera provisional como dirección semántica y editorial.

Se acepta diferir una pasada de microcomposición. Persisten casos puntuales en los que un texto se aproxima demasiado a una caja o llega a superponerse con ella. Esos casos quedan registrados como deuda visual y no deben interpretarse como aprobación definitiva de geometría, espaciado o legibilidad.

La colección debe conservar infografías específicas para cada lectura. La repetición de una familia visual sólo es admisible cuando la relación conceptual representada es realmente equivalente. La paleta queda restringida al sistema METSI aprobado. No se admiten bloques negros dominantes ni colores ajenos a papel, blanco, tinta, grises y volt.

Esta aprobación no autoriza a alterar ahora los PDF publicados. Primero se revisan las fuentes canónicas con la ampliación curricular aprobada, luego se audita el contenido y finalmente se recompaginan los PDF.

## Distribución curricular aprobada

La ampliación refuerza contenidos existentes sin convertir METSI en una preparación para certificaciones ni en una colección de tutoriales de herramientas. Cada incorporación debe conservar la continuidad con Hotel Horizonte, producir una decisión profesional y quedar anclada en bibliografía identificable.

## Orden de ejecución aprobado

1. Preparar una ficha por cada N afectado con ubicación exacta, propósito, contenido nuevo, extensión, bibliografía y relación con Hotel Horizonte.
2. Modificar solamente las fuentes Markdown canónicas después de verificar las fichas.
3. Auditar profundidad, continuidad, solapamientos, registro rioplatense académico, anclajes bibliográficos y control de pérdidas.
4. Integrar las infografías aprobadas y resolver su deuda visual.
5. Recompaginar, revisar los PDF y publicar una versión nueva.

Hasta completar esa secuencia, los PDF actuales se preservan como línea de base y no contienen todavía esta ampliación curricular.
