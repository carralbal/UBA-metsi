# N14 · edición digital post-Cecilia

Esta carpeta contiene la fuente editable íntegra de la lectura N14. `index.html` usa siete hojas CSS enlazadas, dos hojas CSS importadas y 25 recursos locales. La portada aprobada se incorpora desde el PDF público durante el ensamblado; no se rediseña aquí.

Sobre la edición pública anterior se añadió, en el núcleo, un ejemplo ficticio de **un mismo trámite de constancia antes y después**, con frontera estable, estados, responsables, línea de base honesta y medidas propuestas. Se añadió una consigna comparable, y se conservó el caso de alta hospitalaria. De los 307 bloques públicos identificados, ninguno fue eliminado ni reescrito; se agregaron siete. Los tres paneles visuales idénticos de seis personajes de Hotel Horizonte que repetían la primera aparición se retiraron de las aplicaciones posteriores, sin borrar la prosa propia de esas secciones.

La infografía experimental `N14-constancias/proceso-antes-despues.svg` **no forma parte de esta edición**: su QA privado encontró que faltan la rama explícita de baja y la actividad de respuesta de la persona. No se la hace pasar por un BPMN completo. La lectura contiene un ejemplo narrativo de comparación; la producción/corrección formal del modelo sigue siendo trabajo de N16 y del equipo docente.

El PDF digital de esta fuente tiene 46 páginas A4. Su verificación técnica consta en `QA-POST-CECILIA-20261027.md`. Publicación técnica no equivale a aprobación académica, prueba de clase ni edición de imprenta.
