# Texto alternativo · díptico N16

**Hoja 1.** En este caso ficticio, una persona inicia uno o más trámites identificados. El trámite conserva su historial de cambios de estado y puede generar observaciones; a una observación puede responder la misma persona. El estado visible se deriva de esa historia: no puede cambiarse sin huella.

**Hoja 2.** Continúa el mismo trámite. Se distingue una decisión firmada de una baja alternativa. Un aviso identifica observación o decisión, destinatario, canal y entrega real. En esta hipótesis didáctica ficticia, varios intentos fallidos del mismo objeto/finalidad se conservan en **un episodio de reparación** con responsable, próxima acción y cierre comprobado. Bajo P1, Resuelto exige firma, entrega válida de esa decisión y observaciones tratadas; baja no significa Resuelto. El modelo es conceptual, no una norma FCE ni un ER formal validado.
