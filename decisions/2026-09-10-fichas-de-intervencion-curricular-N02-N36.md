Fecha: 10 de septiembre de 2026.

Estado: ubicación y alcance aprobados para edición de contenido. Esta matriz operacionaliza `2026-09-10-infografias-y-ampliacion-curricular.md` y no autoriza todavía recompaginación, regeneración de PDF ni publicación en el sitio.

## Reglas comunes

- Cada incorporación debe modificar una decisión profesional y no funcionar como mención decorativa.
- Hotel Horizonte debe actuar como prueba o aplicación, no como ejemplo intercambiable.
- Las versiones, definiciones y referencias técnicas se verifican contra fuentes oficiales.
- Git se explica como sistema de control de versiones distribuido. GitHub, GitLab y plataformas equivalentes se presentan como realizaciones posibles.
- Scrum, Kanban y PMBOK no se presentan como recetas ni como equivalentes entre sí.
- UI no se usa como sinónimo de UX. La experiencia se analiza sobre el sistema completo, incluidas operación, accesibilidad, contenido y reparación.
- Las incorporaciones regionales deben quedar ligadas a una obra y a una inferencia específica.
- El registro permanece académico e impersonal, con español rioplatense y sin rayas de inciso.
