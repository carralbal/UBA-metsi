# N23 · Rúbrica y evidencias

## Escala

- `0`: conjunto de tareas o componentes;
- `1`: corte visible sin capacidad completa;
- `2`: capacidad útil con operación o expansión incompleta;
- `3`: corte vertical, observable, reparable y aprendible.

## Rúbrica del corte

| Criterio | Pregunta de evaluación | Evidencia de nivel 3 |
|---|---|---|
| Capacidad | ¿Una población logra un outcome? | Completa un episodio bajo condiciones declaradas. |
| Incertidumbre | ¿El corte produce aprendizaje decisivo? | Vincula evidencia con hipótesis y decisión. |
| Verticalidad | ¿Atraviesa las capas necesarias? | Integra reglas, datos, interfaz y operación. |
| Población | ¿El alcance humano está delimitado? | Declara incluidos, excluidos y protección. |
| Excepción | ¿Evita el camino feliz? | Prueba una excepción relevante. |
| Terminado | ¿Incluye uso, observación y reparación? | Supera una prueba sin apoyo extraordinario. |
| Exposición | ¿Distingue desplegar de activar? | Define bandera, monitoreo y reversión. |
| Expansión | ¿El siguiente corte tiene condición? | Reabre hipótesis por volumen, canal o población. |

## Evidencia de aprendizaje

El corte debe completar una llegada anticipada y accesible, y conservar evidencia suficiente para decidir el siguiente paso.

## Conexión acumulativa

La secuencia sólo puede sostenerse si N24 hace explícitas las renuncias y los límites de capacidad.
