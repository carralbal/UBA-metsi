# METSI N24–N36 — registro de retratos de Referentes

Fecha de control: 2026-09-08. Alcance: activos y derechos de imagen. No se modificaron textos canónicos, generadores, PDF ni sitio.

## Criterio de aceptación

Sólo se aprueba una fotografía cuando representa inequívocamente a una persona real, abre como raster, posee página fuente HTTPS, descarga directa HTTPS, creador o crédito, licencia abierta o declaración pública explícita, URL de licencia y huella SHA-256 coincidente. Se rechazaron fotos generadas, monogramas, logos, retratos sin licencia verificable, grupos con identidad ambigua y el retrato de Taiichi Ohno cuya ficha sólo declara dominio público por la regla japonesa para obras corporativas, sin una base internacional suficientemente clara para esta publicación.

La matriz conserva los referentes canónicos cuando existe un activo abierto utilizable. Cuando no existe, propone un reemplazo académico explícito. Ninguna sustitución fue aplicada al canon durante esta tarea.
