# Sistema pedagógico METSI

Esta carpeta transforma la colección N00 a N36 en experiencias de aprendizaje. Los PDF son la preparación conceptual. Los encuentros se reservan para comparar interpretaciones, producir artefactos, introducir evidencia adversa, defender decisiones y registrar revisiones.

## Unidad de producción

Cada Núcleo contará con cuatro piezas coordinadas:

1. `PREPARACION-ASINCRONICA.md`: propósito, lectura, consigna, evidencia de entrada y tiempo estimado.
2. `TALLER-SINCRONICO.md`: secuencia completa, tiempos, agrupamientos, consignas, perturbaciones y cierre.
3. `GUION-DOCENTE.md`: qué se muestra, qué se dice, preguntas de sondeo, respuestas esperables, errores frecuentes y notas de facilitación.
4. `RUBRICA-Y-EVIDENCIAS.md`: criterios observables, instrumento de devolución y vínculo con el portfolio acumulativo.

Una N no equivale mecánicamente a una clase. Los paquetes pueden combinarse según el cronograma aprobado, pero cada uno conserva su aporte conceptual y la evidencia que produce.

## Regla de diseño

- La lectura sucede antes del encuentro.
- La explicación docente ocupa como máximo el tiempo necesario para desbloquear una confusión de alto valor.
- La mayor parte del encuentro se dedica a reconstruir, decidir, contrastar y revisar.
- Hotel Horizonte funciona como caso longitudinal y conserva la numeración HH.
- Cada actividad produce un artefacto breve que puede recuperarse en Núcleos posteriores.
- La evaluación observa la calidad del razonamiento y su trazabilidad, no la repetición de definiciones.
