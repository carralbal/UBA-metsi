# Procedencia de esta publicación

Esta publicación reproduce el estado editorial cerrado del repositorio maestro METSI en el commit local `67f0a04`, fechado el 3 de septiembre de 2026.

Incluye los PDF finales disponibles de N00 a N04, sus fuentes editables, auditorías, manifiestos, contenidos canónicos de N05 a N10 y las skills editoriales vigentes. Los recursos binarios se conservan mediante Git LFS para evitar pérdidas o compresión destructiva. El despliegue de GitHub Pages descarga esos originales antes de ensamblar el sitio.

El historial de producción permanece preservado en el repositorio maestro local. Este repositorio público comienza con una instantánea íntegra y verificable del estado aprobado, creada sin modificar ese archivo maestro.
