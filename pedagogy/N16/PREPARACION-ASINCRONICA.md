# N16 · Preparación asincrónica

## Propósito

Llegar con tres modelos relacionados y utilizar sus diferencias para descubrir decisiones, tiempos o responsabilidades todavía abiertas.

## Producción requerida

Seleccioná tres representaciones de HH-16 o de una situación conocida. Recorré un escenario ordinario y uno adverso y registrá:

- propósito, audiencia, frontera, nivel, resolución y versión de cada modelo;
- correspondencias entre conceptos;
- diferencias terminológicas, temporales, normativas, cuantitativas, de identidad, frontera o autoridad;
- consecuencia y reversibilidad de cada contradicción;
- evidencia necesaria para interpretarla;
- tratamiento: aceptar, traducir, corregir, escalar, posponer o retirar;
- responsable, prueba de cierre y fecha de revisión.

## Prueba de cambio

Elegí una regla nueva y anticipá qué modelos, decisiones y operaciones deberían cambiar. Respondé además dos preguntas de preparación de N16.

## Criterios de entrada

- Coherencia no se confunde con igualdad literal.
- Las diferencias se clasifican antes de corregirse.
- Propósito y tiempo se comparan antes de declarar contradicción.
- Una fuente única no se presume verdadera.
- Todo modelo tiene revisión, reemplazo y retiro posibles.
