# Texto alternativo

Cuatro vistas de Hotel Horizonte usan la palabra entregable para condiciones
distintas. Proceso exige inspección, asignación y acceso. Estados la usa para
una habitación preparada en inventario. Experiencia la vincula con la
confirmación recibida por el huésped. El tablero la cuenta desde la limpieza
terminada. Las cuatro afirmaciones atraviesan un mismo episodio, la reserva R73,
para contrastar propósito, nivel, tiempo, identidad, evidencia y autoridad. La
diferencia se clasifica como legítima, error verificable, brecha temporal o
tensión abierta. Luego se asigna un tratamiento, corregir, decidir, investigar o
aceptar riesgo, con efecto, responsable, plazo y condición de cierre. Una línea
final muestra el ciclo de vida del modelo: proponer, validar, usar, revisar y
retirar. La baseline es suficiente para decisiones explícitas, pero no se trata
como verdad eterna.
