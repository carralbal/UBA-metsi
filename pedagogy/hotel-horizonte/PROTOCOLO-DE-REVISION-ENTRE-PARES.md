# Hotel Horizonte · Protocolo de revisión entre pares

## Propósito

La revisión no busca corregir el estilo del equipo ni imponer una solución. Debe encontrar una relación que se sostiene, una fisura que importa y una prueba capaz de cambiar una decisión.

## Organización

- Se revisa entre equipos, con asignación docente para evitar reciprocidad automática.
- Participan dos integrantes por equipo revisor y luego informan al equipo completo.
- La revisión dura entre quince y veinticinco minutos según el hito.
- Toda observación debe citar un fragmento, modelo, dato o ausencia concreta del dossier.

## Secuencia

### 1. Reconstrucción sin explicación del autor

El equipo revisor escribe en una oración:

- qué capacidad intenta sostener el dossier;
- para qué población y condiciones;
- qué decisión considera defendible.

Si no puede reconstruirlo, registra dónde se pierde la cadena. No solicita primero una explicación oral.

### 2. Prueba de trazabilidad

Selecciona una afirmación central y recorre:

`procedencia → transformación → interpretación → decisión → condición de revisión`

Registra el primer vínculo que no puede comprobar.

### 3. Prueba adversa

Formula una objeción que, si fuera cierta, cambiaría una decisión. Debe indicar qué evidencia permitiría confrontarla.

### 4. Prueba de consecuencias

Identifica quién recibe el valor, quién queda expuesto, quién puede detener y quién debe reparar. Señala cualquier ausencia relevante.

El equipo no debe aceptar toda observación. Para cada devolución relevante registra:

|---|---|---|---|---|
| | | | | |

## Conductas que invalidan la revisión

- proponer una solución sin reconstruir la pregunta;
- evaluar sólo claridad, diseño visual o cantidad de contenido;
- afirmar “falta información” sin decir qué decisión depende de ella;
- usar una preferencia metodológica como criterio universal;
- pedir que el equipo adopte la devolución sin justificar su consecuencia.
